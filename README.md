# Human Activity Recognition with a Hidden Markov Model (from scratch)

Formative 2 (individual assignment): *Modeling Human Activity States Using Hidden Markov Models*.

A Gaussian-emission HMM implemented **from scratch with numpy** (forward, backward, Viterbi, Baum-Welch) decodes four activities,
**Still, Standing, Walking, Jumping**, from smartphone accelerometer and gyroscope recordings (Sensor Logger). No HMM library is used.
Only `numpy`, `pandas`, `scipy`, `matplotlib` and `seaborn` are needed for the model and notebook.

## Results (unseen data, Viterbi decoding)

| Test set | Windows scored | Overall accuracy |
|---|---|---|
| 2 required unseen files (`jumping_test_01`, `still_test_01`, iPhone 11 Pro) | 133 | 0.962 |
| 2 unseen files + continuous multi-activity clip | 163 | 0.920 |
| multi-activity clip alone | 30 | 0.733 |

The two unseen files contain only Still and Jumping, so Walking and Standing metrics come from the multi-activity clip (6 and 8 windows only).
Jumping in the multi-activity clip is much gentler than in the training clips and is mostly decoded as Walking. See the report for the discussion and limitations.

## How to run

```bash
pip install -r requirements.txt
cd notebooks
jupyter nbconvert --to notebook --execute --inplace hmm_activity_recognition.ipynb   # or open it in Jupyter and Run All
cd ../report && python build_report.py                                               # rebuilds report/report.pdf from the notebook outputs
```

The notebook reads only `data/raw/` and `data/recordings_manifest.csv`, writes `data/processed/`, `data/*.csv`, `figures/*` and `figures/results.json`,
and runs top to bottom with fixed random seeds (seed 42).

## Data notes

* Recordings: walking, jumping (x2), standing at waist level, still on a flat surface (recorded with the gravity channel on); two unseen test clips (jumping, still) recorded on a different phone; one continuous multi-activity clip (Still, Standing, Jumping, Walking).
* All signals are harmonised to 50 Hz, trimmed by 3 s at both ends and split into 10 s chunks; windows are 2 s with 50% overlap and never cross chunk borders.
* `jumping_test_01` was recorded at the same moment as `jumping_train_01`, so the overlapping part of the training clip is removed (see notebook section 2).
* The multi-activity segment boundaries (Still 0-10 s, pick-up transition 10-12 s, Standing 12-21 s, Jumping 21-31.5 s, Walking from 31.5 s) were read from the signal and confirmed by the author.
* Training sequences for the HMM are random concatenations of 10 s chunks (no training recording contains several activities), so the off-diagonal transition probabilities are a construction choice, not measured behaviour.
